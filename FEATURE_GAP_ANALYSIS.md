# TGVPANEL Feature Gap Analysis

**Audit baseline:** branch `arena/67092fb3-tgvpanel`, based on `fb6d565` (merged scheduled-snapshot PR #38). This is an existing Node.js/TypeScript + Express + EJS + SQLite product; recommendations below extend its modules and do not propose a rebuild or replacement control panel. Findings were cross-checked against `src/`, `app.js`, EJS pages, migrations, scripts, tests, README and the existing `docs/PHASE1_SOURCE_AUDIT.md` (which contains some historical claims that should not be treated as current test evidence).

## Requested roadmap checklist (individual capability status)

`FULLY IMPLEMENTED` is reserved for a named operation, not an entire roadmap area. Examples of fully implemented/tested slices include TOTP enrollment/login, authenticated KVM/LXC ownership checks, and scheduled LXC snapshot retention; they do not make their broader roadmap areas complete. `BROKEN` is used only for a reproduced defect; no additional broken feature was confirmed in this audit. Every `PARTIALLY IMPLEMENTED` entry names the existing part and does not imply parity. The existing generic bearer PAT remains compatible for its existing use but is `NEEDS SECURITY IMPROVEMENT` for sensitive reseller automation; the separate HMAC reseller-key system is the scoped solution.
